## Problem
Tracking risks, policies, controls and audit evidence for ISO 27001 by hand is slow and hard to keep consistent. The goal was a single tool where compliance data lives in one place.

## Context
Built as a prototype during a 1-month AI summer internship at DRÄXLMAIER Group Tunisia – IT Center. *(Note: certain details are generalized to respect project confidentiality.)*

## Architecture
- **Backend**: ASP.NET Core 8 (C#), Clean Architecture, MediatR / CQRS.
- **Frontend**: React 19 + TypeScript + Tailwind.
- **Data**: PostgreSQL via EF Core; file storage on MinIO.
- **Infra**: local stack with docker-compose.

## Technology
| Technology | Role |
|---|---|
| ASP.NET Core 8 | API, business logic, Clean Architecture |
| React 19 + TypeScript | Web interface and dashboard |
| PostgreSQL (EF Core) | Data model and audit trail |
| MinIO | Evidence file storage |
| JWT + RBAC | Authentication and role-based access (6 roles) |
| pgvector | Schema prepared for a future RAG layer |

## Modules implemented
1. **Risks**: assessment and treatment.
2. **Policies**: approval workflow.
3. **Frameworks**: requirement ↔ control mapping.
4. **Evidence** and **SoA report**.
5. **Audits**: checklist, findings, corrective actions.
6. **Dashboard**: rule-based compliance rate per framework (compliant / non-compliant / not assessed).

## Engineering
Every change is recorded in an automatic audit log by overriding `SaveChangesAsync` in EF Core. API endpoints are protected by JWT authentication and role-based access control. The project includes 3 unit tests (xUnit, Moq).

## Status & next step
The AI layer is **not finished**: the pgvector schema is in place, but the assistant interface is not yet connected. The next step is a RAG assistant over policies and ISO 27001 requirements.
