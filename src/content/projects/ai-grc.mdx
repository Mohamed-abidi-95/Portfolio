## The problem
Checking internal policies against standards such as **ISO 27001** and **ISO 9001** is slow manual work: someone has to read both sides and spot what is missing.

## What I built
During my internship at the DRÄXLMAIER IT Center, I built a **prototype** of an intelligent GRC (governance, risk & compliance) assistant. *(Some details are generalized to respect confidentiality.)*

- Designed a **RAG pipeline**: document ingestion, embeddings, semantic search and contextualized answer generation.
- Used a **vector database** to compare internal policies with standard requirements.
- Prototyped **compliance gap detection** and **automatic summarization** of audit documents.

## Platform around the assistant
| Layer | Technology |
|---|---|
| Backend | ASP.NET Core 8 (C#), Clean Architecture, MediatR / CQRS, REST API |
| Frontend | React 19 + TypeScript + Tailwind |
| Data | PostgreSQL (EF Core), MinIO for evidence files |
| Security | JWT authentication, role-based access control |
| Traceability | automatic audit trail of every change |

The platform covers risks, policies with an approval workflow, requirement ↔ control mapping, evidence, SoA report, audits and a dashboard.

## What I learned
For compliance, **traceability** matters as much as the AI: who changed what, who can see which document, and where each answer comes from.
