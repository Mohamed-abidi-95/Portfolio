## The idea
AutiConnect is a support platform with an AI assistant that answers in **French and Arabic**.

## AI assistant
- Chatbot built on **Gemini 1.5 Flash**.
- **Function calling**.
- **Validated JSON outputs**, so the backend only works with well-formed answers.

## Backend
- **Node.js REST API**.
- Authentication with **JWT** and role management.
- **MySQL** database.

## What I learned
Treating the LLM like any other API — with a contract, validation and errors to handle — is what makes it usable inside a real application.
