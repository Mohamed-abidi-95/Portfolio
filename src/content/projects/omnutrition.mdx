## Problem
A predictive model was required to analyze nutritional data, alongside a web application to present the insights to end users.

## Architecture
- **Frontend**: React application for user interaction.
- **Backend**: FastAPI for serving predictions and handling business logic.
- **Data Science**: Python ML pipeline for training and inference.

## Technology
| Technology | Role |
|---|---|
| Python & Scikit-learn | Data processing and model training |
| FastAPI | High-performance backend API |
| React | Interactive frontend |

## Results
Trained and deployed a `RandomForestRegressor` that achieved an R² score of 0.993, indicating highly accurate predictions on the nutritional dataset.

## What I learned
Integrating machine learning models into a full-stack web application requires careful API design to ensure fast inference times and a smooth user experience.
