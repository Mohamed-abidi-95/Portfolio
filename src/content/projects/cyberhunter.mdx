## The idea
A platform that helps analysts read security logs, spot anomalies and map events to the **MITRE ATT&CK** framework.

## Features
- Security log analysis and **anomaly detection**.
- Mapping of detected events to **MITRE ATT&CK**.
- **GeoIP** and **IP-reputation** enrichment.
- Dashboards for a quick overview.

## Stack
A **Slim 4 (PHP)** backend with a web interface for the dashboards.

## What I learned
Security tools are only useful if analysts can read them quickly: enrichment and clear dashboards matter as much as detection.
