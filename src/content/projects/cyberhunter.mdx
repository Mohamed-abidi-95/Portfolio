## Problem
Security analysts needed a centralized platform to detect threats and map them to the MITRE ATT&CK framework.

## Architecture
- **Backend**: Slim 4 (PHP) micro-framework for lightweight, fast API endpoints.
- **Frontend**: Modern web UI for visualizing threats.
- **Integration**: Mapping detected events to the MITRE ATT&CK matrix.

## Technology
| Technology | Role |
|---|---|
| Slim 4 (PHP) | Backend API development |
| Cybersecurity | Threat modeling and detection logic |

## Results
Developed a functional threat detection platform that successfully categorizes and maps security events, providing a clear overview of potential attack vectors.

## What I learned
Building cybersecurity tools requires a deep understanding of standardized frameworks like MITRE ATT&CK and the ability to design secure, efficient backend architectures.
